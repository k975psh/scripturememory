## ✨ 주요 기능 (Features)

* 🎯 **정밀한 3단계 섹션/서브섹션별 암송 점검**:
  * 60구절 (A~E 5개 파트), DEP (8개 대주제 및 44개 세부 서브섹션), Series (1~5 각 36구절 및 15개 세부 서브섹션), 주제별 60구절(찬양/약속/훈련/전도/인격) 등 원하는 단위로 정밀 선택 가능
* 💾 **스마트 진도 기억 (Local Storage)**:
  * 파트별·하위 섹션별·언어별로 마지막 완료한 구절 번호를 브라우저에 자동 저장하여 다음 접속 시 자동으로 이어서 점검
* 👁️ **블러(Blur) 가림막 & 단일 구절 집중 모드**:
  * 카드 한 장당 1구절씩 집중 표시되며, 본문 터치/클릭 시 정답 본문 표시
* ⌨️ **단축키 & 모바일 스와이프 제스처**:
  * PC: <kbd>Space</kbd> (정답 확인/가리기), <kbd>→</kbd> 또는 <kbd>Enter</kbd> (다음 구절), <kbd>←</kbd> (이전 구절)
  * 모바일: 화면 터치 (정답 확인/가리기), 화면 좌측 스와이프 (다음 구절), 화면 우측 스와이프 (이전 구절)
* 📱 **PWA(Progressive Web App) & 100% 오프라인 지원**:
  * 스마트폰 홈 화면에 추가 시 브라우저 주소창 없는 독립형 앱으로 실행
  * Service Worker 캐싱을 통해 인터넷이 없는 곳(비행기 모드, 지하 등)에서도 완벽 작동
* 🌐 **한글(개역한글) / 영문(NIV) 지원**:
  * 60구절, 5확신, 8구절 등 주요 파트의 다국어 암송 지원

## 🚀 GitHub Pages 배포 방법 (1분 완성)

1. **GitHub 저장소 생성**:
   * [GitHub.com](https://github.com/) 접속 후 `New repository`를 생성합니다. (Public 권장)
2. **파일 업로드**:
   * `index.html`, `verses.json`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` 파일을 업로드하고 커밋(`Commit changes`)합니다.
3. **GitHub Pages 활성화**:
   * 저장소 메뉴의 **`Settings`** ➔ **`Pages`**로 이동합니다.
   * **Branch** 설정을 `None`에서 **`main`** (또는 `master`), 폴더는 **`/ (root)`**로 선택하고 **`Save`**를 누릅니다.
4. **완료**:
   * 약 1분 후 생성되는 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소로 즉시 접속하여 사용할 수 있습니다.

## 📲 스마트폰 앱(PWA)으로 설치하는 방법

* **아이폰 (iOS / Safari)**:
  1. Safari 브라우저에서 배포된 웹 주소로 접속합니다.
  2. 하단 중앙의 **공유 버튼(네모에 위 화살표)**을 탭합니다.
  3. 목록에서 **[홈 화면에 추가]**를 선택합니다.
* **안드로이드 (Android / Chrome)**:
  1. Chrome 브라우저에서 배포된 웹 주소로 접속합니다.
  2. 상단 메뉴(점 3개)를 누르고 **[앱 설치]** 또는 **[홈 화면에 추가]**를 선택합니다.

> 💡 **홈 화면에 생성된 아이콘을 터치하면 상단 주소창이 없는 풀스크린 네이티브 앱으로 실행되며, 인터넷 연결 없이도 동작합니다.**

## 💻 로컬에서 직접 실행하기

별도의 외부 프레임워크나 패키지 설치 없이 브라우저에서 실행할 수 있습니다. `verses.json`을 `fetch`로 불러오므로 간단한 로컬 웹 서버를 실행합니다:

```bash
# Python 3 내장 웹 서버 실행
python -m http.server 8000
```
브라우저에서 `http://localhost:8000`으로 접속합니다.
